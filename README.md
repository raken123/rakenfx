# Raken FX Labs

A small lab of playful AI experiments in one self-contained page. Open `index.html` in a browser.

| ID | Experiment | What it does |
|----|------------|--------------|
| FX-01 | Bookify | Turns one idea into an illustrated book of 10 to 200 pages. Quick engine: GPT 4o + GPT Image 2.5 Flare. Deep engine: GPT 5.6 Sol + GPT Image 2.5 Sunburst. |
| FX-02 | It's an image that you can see around, kind of Nano Banana but you can look around the image | Text or image to a 3D model you can orbit, using GPT 6 Astra with up to 8K textures. |
| FX-03 | Showtalk | You host an animated talk show with fictional guests over a GPT Live 1 session, and run it with cues. |
| FX-04 | Hello Workie! | A phone helper (Android) whose face flies to your Mac or Windows computer, does a task, and flies back. |

This is a prototype: model calls are simulated in the browser, so nothing typed leaves the page. The 3D viewer loads three.js r128 from cdnjs.
